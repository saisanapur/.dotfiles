# Sai's Weakness Register

Personal log of observations about gaps in: (a) my harness, (b) prompting, (c) the Access Management product, (d) team processes. Lightweight capture; weekly synthesis turns these into routed follow-ups via `sai-weakness synthesize`.

**Format per entry:**

```
- YYYY-MM-DD #tag1 #tag2 — observation as written, with file/PR/skill references when relevant.
```

**Default tags:**

- `#harness` — sai-wip skills, hooks, settings, automation, scaffolding
- `#prompting` — phrasing, context loading, agent dispatch patterns, clarification fatigue
- `#product` — Access Management UX, customer pain, feature gap, friction point
- `#team-process` — standup, forum, sprint planning, code review process, team norms

Free-form tags are allowed when none of the defaults fit. After 4 weeks of entries, audit tag distribution and consider canonicalizing.

**Synthesis marker:** entries that have been counted in a Friday digest end with ` (synthesized YYYY-MM-DD)`. Don't edit those by hand — `synthesize` mode manages them.
